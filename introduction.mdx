**CarLogger** — це веб-додаток для власників авто, який допомагає тримати всю важливу інформацію про транспортний засіб в одному місці.

## Що можна робити

<CardGroup cols={2}>
  <Card title="Гаражі" icon="warehouse">

  </Card>
  <Card title="Бортовий журнал" icon="wrench">

  <Card title="Трекер ТО" icon="calendar-check">
    Налаштуйте планові роботи — заміна масла, фільтрів тощо. Система нагадає коли підійде час.

  <Card title="Облік пального" icon="gas-pump">

## Технічний стек

CarLogger побудований на сучасних технологіях:

- **Vue 3** — інтерфейс
- **Pinia** — управління станом
- **Supabase** — база даних та авторизація
- **Naive UI + PrimeVue** — UI компоненти
- **Vite** — збірка проекту
