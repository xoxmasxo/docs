Вкладка **«Пальне»** (або **«Енергія»** для електромобілів) дозволяє вести детальний облік кожної заправки.

## Підтримувані типи палива

| Тип | Одиниця |
|-----|---------|
| Бензин | літри |
| Дизель | літри |
| Електро (зарядка) | кВт·год |
| Газ | літри |
| AdBlue | літри |

<Note>
  Тип палива за замовчуванням підставляється автоматично з біографії авто. Для дизельних авто доступні також записи AdBlue. Для гібридів — усі типи.
</Note>

## Додавання запису

<Steps>
  <Step title="Натисніть «Додати запис»">
    Кнопка у верхньому куті вкладки.
  </Step>
  <Step title="Вкажіть деталі заправки">
    - **Тип палива** — визначається автоматично або обирається вручну
    - **Дата** — за замовчуванням сьогодні
    - **Пробіг** — обов'язкове поле
    - **Об'єм** — літри або кВт·год
    - **Загальна вартість** — у гривнях
  </Step>
</Steps>

## Перегляд та редагування

Всі записи відображаються у таблиці за датою. Кожен запис можна відредагувати або видалити за допомогою іконок у колонці **«Дії»**.
