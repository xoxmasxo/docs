# pidvoda — Документація

Офіційна документація для [pidvoda](https://github.com/xoxmasxo) — веб-додатку для відстеження стану автомобілів.

📖 **Онлайн:** [pidvoda.mintlify.app](https://pidvoda.mintlify.app)

## Структура

```
index.mdx                         # Головна сторінка
getting-started/
  registration.mdx                # Реєстрація та вхід
  garages.mdx                     # Гаражі
  vehicles.mdx                    # Автомобілі
vehicle-features/
  bio.mdx                         # Біографія авто
  maintenance-log.mdx             # Бортовий журнал
  maintenance-tracker.mdx         # Трекер ТО
  fuel.mdx                        # Пальне
  notes.mdx                       # Нотатки
faq.mdx                           # Часті питання
docs.json                         # Конфігурація Mintlify
```

## Локальний запуск

```bash
npm i -g mintlify
mintlify dev
```

Відкрийте [localhost:3000](http://localhost:3000) у браузері.
